# Agenda de cumpleaños

Aplicación Android sencilla para recordar cumpleaños y felicitar por WhatsApp.
Los datos se guardan únicamente en el móvil de cada persona.

- `src/index.html`: la aplicación.
- `android/`: envoltorio Android (Capacitor).
- `.github/workflows/build.yml`: compila y firma la APK y la publica como *release* al crear una etiqueta `vX.Y.Z`.
